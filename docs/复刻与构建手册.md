## 0\. 一句话说清这个项目是什么

用原版《多克多比》（淘米，2011–2013 的儿童页游）的**归档素材 + 策划文档**，
重建成一个**纯静态、零第三方依赖、双击即玩**的离线单机版：

* **成品**：`多克多比v0.8单机版.zip`（172.1 MB / 5146 条目）→ 解压 → 双击 `多克多比.exe`
* **本体**：一份 HTML/JS/Canvas 游戏，没有框架、没有构建步骤、没有 npm 依赖
* **性质**：**官方素材 + 官方文档重建**，不是逐字节复刻。哪些是官方的、哪些是推算的，
每一处都带来源等级（`official` / `derived` / `community` / `missing`）——这是本项目的硬规矩（R2）

## 2\. 从零重建 v0.8：确切命令

分四段。**A 段是"只要能跑就跑得通"的最小路径**（不改任何素材）；
B/C 段只有在你**动了素材**时才需要。

### A. 打包（最常用，约 3–5 分钟）

```powershell
# 1) 开工自检：核对计划书 / STATE / 发布包 的 6 个数字是否一致（只读，1 秒）
node \\\_tools/check-plan-freshness.mjs

# 2) 组装 dist + 打 zip + 校验内容（版本号从 STATE.md 读，也可显式指定）
node \\\_tools/make-release.mjs --ver=v0.8
#    产物：多克多比v0.8单机版.zip

# 3) 校验发布包（20 项）
node \\\_tools/verify-zip.mjs

# 4) 真启动一次 exe 冒烟（12 项：启动 / \\\_\\\_ping 200 / game.html 200 / \\\_\\\_save / 不双开）
node \\\_tools\\\\smoke-exe.mjs
```

`make-release.mjs` 内部做五步，**每一步都会打印证据**（R11 要求"三次实测的证据必须打出来"）：

```
1) 版本号（单一事实源 = STATE.md，会同步写回 STATE.md 与 00-PLAN.md）
2) 组装 dist（调 \\\_build/make-dist.mjs：拷 web 文件 + 用 csc.exe 编译启动器）
3) 打包 zip
4) 校验发布包内容（规则与 verify-zip.mjs 一致）
5) 验收凭据（包名 / 字节数 / 条目数 / 校验结果）
```

> \\\*\\\*坑（实测踩过）\\\*\\\*：`--ver` 原先只认 `--ver=X`。
> 写成 `--ver v0.8`（空格）会\\\*\\\*静默按旧版本号打包\\\*\\\* —— 包名还是旧版、退出码 0、所有校验全绿。
> 第 67 轮已修成三种写法都吃（`--ver=0.8` / `--ver=v0.8` / `--ver v0.8`）。
> \\\*\\\*教训：打完包要核"包名本身"，不能只看退出码。\\\*\\\*

## 4\. 为什么必须标注来源等级

这是本项目最重要的一条工程约定（R2）。**归档里有的**和**我们推算的**混在一起时，
如果不标，下一个人（或下一个 AI）会把推算当成官方事实，然后在此基础上继续错。

四级：

|等级|含义|例子|
|-|-|-|
|`official`|归档里有直接依据|场景底图、技能数值、怪物属性、16 个官方场景名|
|`derived`|本项目按依据推算的|77 个场景名、11 座岛名、形态价格档、副本掉落绑定|
|`community`|来自玩家社区资料（论坛/攻略站）|部分玩法描述|
|`missing`|归档里没有，**不编**|22 只无立绘形态、2 个无规则小游戏、S/A 分数线、`music006`|

数据里可以程序读取的地方都带 `conf` 字段（例如 `assets/manifest.json` 的 `scenes\\\[].conf`），
**不是只写在文档里**。

## 8\. 常见坑（都是实测踩出来的，写下来省你几小时）

1. **沙箱里 Node 的 `child\\\_process` 走管道 stdio 会 EPERM**。
要么 `{ stdio: 'inherit' }`，要么把子进程输出落到文件再读。
（很多脚本都有这个注释，别以为是笔误。）
2. **PowerShell 单引号里反斜杠是字面量**。曾有脚本把路径按 JS 字符串规矩写成 `C:\\\\\\\\Users\\\\\\\\...`，
一路没暴露，直到某次缓存没命中才炸。
3. **`node -e "..."` 里写中文/引号很容易被 PowerShell 吃掉**。
要写多行 JS 就**落成文件**再跑，别硬塞进 `-e`（本项目多次因此踩坑）。
4. **`Select-Object -First N` 会提前掐断上游写入者**，用它截长输出要小心。
5. **无头像素画布只支持部分 Canvas API**：没有 `arcTo`、没有 `quadraticCurveTo`。
画圆角矩形要自己用 `arc` + `lineTo` 拼。
6. **无头环境不解 JPEG**（见 §2 C 段的 `convert-jpg.mjs`）。
7. **参数被静默忽略是最危险的一类 bug**（`--ver v0.8` 那次）。
打完包**核产物名**，不要只看退出码。
8. **本工作区可能有两个会话同时改**（曾有一个会话在做高清立绘线）。

# 战斗/界面「还原页游」清单

> 目的：用户要求「**战斗画风尽量还原页游**」，之后背包等界面也要照做，为的是**还原童年那味儿**。
> 所以这份清单是**照着画**的唯一依据 —— 每一条都写清"原版长什么样 / 我们现在什么样 / 差异"。
>
> **证据来源**：`多克多比专区资料素材\图片资源\游戏截图\` 下的原版截图（下称"原版图"）。
> 版式与色值来自 `_tools/probe-battle-ui.mjs` 的**逐像素取样**（PNG 用 node:zlib 自己解，零依赖）
> 与 `image_scan` 的网格读数。凡是**读出来的**都标「实测」，凡是**推断的**都标「推断」。
>
> 更新时间：第 51 轮（2026-09-27）

---

## 0. 一句话结论

原版**不是"一整片暗色"**，而是**两套风格**：

| 场景 | 原版风格 | 实测依据 |
|---|---|---|
| **战斗** | 暗底（暗青 `#04161a`）+ **亮黄名牌** + **底部黄色分段指令条** | `战斗截图.jpg` 取样 |
| **人物/技能面板** | **白 + 青**的亮色面板，青绿描边、彩色图标 | `人物面板.jpg` / `技能面板.jpg` 读数 |

我们现在**两套都做成了同一种暗色冷调**，所以"不像"。**还原 = 把这两套面板分别画对。**

### 1.3 我们现在的实现 vs 原版

| 项 | 我们现在 | 原版 | 判定 |
|---|---|---|---|
| 战斗名牌 | **完全没有**（名字只在探索界面的队伍卡里） | 左上亮黄板 + 名字 + HP/MP | ❌ 缺 |
| 顶部 | 一条暗渐变 `rgba(4,8,16,.85)` + 一行"⚔ 对战中 场景名" | 两块名牌 | ❌ 不像 |
| HP 条色 | `#ff5f5f` 红 | `#7598c0` 蓝灰 | ❌ 色相反了 |
| MP 条 | 无独立条 | `#2c95fe` 亮蓝 | ❌ 缺 |
| 底部指令条 | `rgba(8,14,30,.94)` 深蓝框 + `#3aa0e8` 蓝描边 + 6 个 66×66 方格 | **黄色分段条** | ❌ 完全不像 |
| 敌方名牌 | 右侧 250×48 暗块 + 属性色描边 | 右侧蓝底信息块 | ⚠️ 位置对、风格要改 |
| 战斗台座（椭圆地面） | 有（蓝/红各一块） | 原版图里没有明显椭圆台座 | ⚠️ 可能多余 |

### 1.4 改动方案（本轮）

1. **左上角战斗名牌**：亮黄板 `#fff18b` + 红字名字 `#e33300` + 深蓝信息框 + HP 条 `#7598c0` + MP 条 `#2c95fe` + 数值文字；
2. **敌方名牌**：同风格，右侧对齐（多人时向下排列）；
3. **底部指令条**：改成原版的**黄色分段条** —— 底色暖黄、分段线、右下留技能图标位；
4. 去掉/弱化原版没有的椭圆台座（**先保留**，因为它是"把角色放在地上"的必要视觉手段，
   等截图对比后再决定 —— 记为「待确认」）。

## 1.5 已完成（第 51 轮）

| 部位 | 原版实测 | 实现 | 状态 |
|---|---|---|---|
| 玩家名牌 | 亮黄板 `#fff18b` + 红字名 `#e33300` | 亮黄渐变板 + 红字名 + `Lv.` | ✅ |
| HP 条 | `#7598c0`（蓝灰） | 蓝灰渐变 + `当前/上限` 数字 | ✅ |
| MP 条 | `#2c95fe`（亮蓝） | 亮蓝渐变 + 数字 | ✅ |
| 敌方名牌 | 右上、与玩家同高 | 右侧同款，多人向下排 | ✅ |
| 底部面板 | 深蓝 `#1d2f6e`→`#0c3635` 渐变 + 浅蓝双描边 | 同上 | ✅ |
| 指令格 | **64×64**、格间 **11px**、浅银灰 `#ced5e8`→`#bcbac7` + 浅蓝描边 `#afbfcf` | 57×66、格间 9、同色系（为塞下 5 格+圆钮+左侧区缩了比例） | ✅ |
| 指令格文字 | 深色字压浅底 | 深蓝 `#1b2b52`（选中态亮金） | ✅ |
| 左下消息框 | 白底 `#cdd3e1` | 白底消息框，滚动最近播报（最多留 5 条） | ✅ |
| 左下三个橙钮 | 橙 `#f07a1b` 方钮 | **返/速/聊** 三钮，**都有真功能** | ✅ |

**三个橙钮的功能**（不做摆设）：

| 钮 | 功能 |
|---|---|
| **返** | 退出战斗（点一次问"再点一次就退"，点两次真的走 `playerAct('escape')`） |
| **速** | 战斗速度 1×→2×→3× 循环 |
| **聊** | 快捷发言（4 句预设），发言进消息框 |

**踩过的坑（写下来免得重犯）**：

1. **加宽左侧面板后，三个钮压住了原来的"敌人 2/2 · 回合 1"** —— 截图才发现。
   解法：把这两条信息**移进消息框上方**的状态行，不再单独占一块面板。
2. **按钮图标不能用 emoji/箭头**：本作文字走自制字形图集，`←`/`☰`/`💬` 全画成空方框
   （截图里能看到）。改成汉字 **返/速/聊**。字形检查还抓出注释里的 `☺` 也不在图集里，一并清掉。
3. **消息框一开始显示字面量 `undefined`** —— 没播报时的兜底写漏了。
4. **名牌位置试了四次**才不重叠（`y=16` 被队伍卡盖 → `y=52` 仍重叠 22% → 卡片右侧撞"龙多比"文字 → 定稿 `x=12,y=74`）。

### 1.7 观察名单（偶发，未复现）

`test-battle-mouse.mjs` 在全量回归里**偶发**出现 4 项失败（单独连跑 3 次均 19/19 通过）。
怀疑与"多个测试文件在同一进程里连续跑"有关（`L.battleBtns` 是绘制时写入布局对象的，
若某个用例只驱动输入、不绘制，`hoverBattleBtn` 可能残留）。**暂不改**，但下次再出现要优先查这里。

## 4. 纪律备注

- **不许凭印象画**：本条目的每个数字都指向原版图；改完必须**截图对比**（`_tools/shoot.mjs --battle-only`）。
- 改样式**不能**把面板画到画面外或压住文字 —— 每次都要跑
  `_tools/ui-overlap.mjs` 与 `_tools/check-canvas-bounds.mjs`。
- 颜色若与原版取样有偏差，**以取样为准**（取样脚本可复现：`node _tools/probe-battle-ui.mjs <png>`）。

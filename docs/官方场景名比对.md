- 带官方中文名的场景原图：**26 张**，覆盖 **16 个不同的官方名**
- 其中**判定为"很可能同图"的官方名：11 个** → 图书馆(→42)、城堡走道(→43)、城堡郊外(→28)、智慧学堂(→32)、熔岩池(→57)、空中蔓步(→39)、藤顶风光(→50)、光暗峡谷(→44)、征服平原(→85)、黑暗裂缝(→87)、布拉德矿坑(→33)
- 出现在**两张以上原图**里的官方名：10 个；其中 **7 个多张原图一致指认到同一张场景** —— 这是交叉验证：
  图书馆→scene_42.jpg、城堡走道→scene_43.jpg、城堡郊外→scene_28.jpg、智慧学堂→scene_32.jpg、熔岩池→scene_57.jpg、空中蔓步→scene_39.jpg、藤顶风光→scene_50.jpg

   上面这 7 个经核对是前者 —— `场景\` 的 jpg 与 `多克多比素材fla\…\场景素材\` 的 png。）
- **在我们的 88 张场景里找不到对应的官方名：5 个** → 云中城堡、城堡大厅、燃烧瀑布、幽水宫、邪力宫殿

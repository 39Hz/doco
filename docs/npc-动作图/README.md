# NPC 的全部移动动作图（从归档里导出的原始帧）

> 由 `_tools/_npcexport.mjs` 从 `assets/anim/时装序列/` 导出，**逐帧原样复制**，没有做任何加工。
> 单帧尺寸 **218×320 上下**，`fps: 24`（写在 `assets/anim/index.json` 里）。

## 一共多少

| 造型 | 动作数 | 帧数 |
|---|---|---|
| 化妆女 / 化妆男 / 喵喵女 / 喵喵男 / 狮子女 / 草莓女 / 草莓男 / 蝙蝠女 / 菠萝男 | 各 4 | 各 68 |
| **狮子男** | **7** | **119** |
| 合计 | — | **731 帧** |

四个动作的命名是统一的：**正面一 / 正面二 / 背面一 / 背面二**（个别造型还多出 正面三 / 正面四 / 背面三）。
每个动作都是 **17 帧**（狮子男的额外动作也是 17 帧）。

## 哪个是"真·走路"（量出来的，不是猜的）

判据：帧间的**下半身轮廓变化**与**内容水平重心的移动量**。

| 造型 | 下半身变化 | 水平位移 | 判定 |
|---|---|---|---|
| **喵喵女 / 喵喵男** | **0.19 ~ 0.20** | **8.5 ~ 10.4 px** | **真·走路**（身体左右移、尾巴甩、姿势逐帧变） |
| 化妆男 / 草莓女 / 草莓男 | 0.08 ~ 0.17 | 1.6 ~ 3.6 px | 有动作，幅度小 |
| 狮子女 / 狮子男 / 蝙蝠女 | 0.05 ~ 0.08 | 0.2 ~ 1.4 px | 基本是**待机小动作** |

结论：**要参考/借用走路循环，看「喵喵」那两套**。想看全部 10 套的横向对比，直接开各套的 `-总览.png`。

## 游戏里怎么用这些帧（`game.js` 的 `drawCostumeFigure`）

- **朝向**：`facing === 'up'`（往上走）用**背面**帧，其余用**正面**帧；朝左是把正面帧**水平翻转**。
- **待机 / 走路**：站着时放 `正面一`（背面同理用 `背面一`），走路时在 `正面一 ↔ 正面二` 之间交替；
  帧速 `moving ? t*14 : t*4`。
- **NPC 拿到哪一套**：`hash(NPC名字 + 场景号)` 稳定挑一套，并且**同一屏不撞衫**（重复就顺延）。
  例：`拉鲁`（场景 2）→ 喵喵女；`克里文`（场景 1）→ 狮子女；`艾伦`（场景 1）→ 草莓女。

## 顺带说明（和"主角走路"那件事的关系）

- 归档里**多比的走路循环是没有的**：`多比形态序列` 只有 2 只（光多比 / 凤凰多比），
  而且全是**战斗动作**（发招一~四 / 闪躲 / 防御 / 胜利 / 普通姿态 / 动作一~六）。
- 所以**主角要走出"腿真的分开"的效果，只能走这条路**：用这里的时装走路帧
  （原版的玩家本体就是多克，多比是战斗形态）。

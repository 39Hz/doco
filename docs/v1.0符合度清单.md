## 0. 「完全符合原版」在本项目里的定义

归档里**有依据**的，必须逐条对上（数值 / 名字 / 规则 / 界面文案）；
归档里**没有依据**的，只能标 missing —— **不许拿推算值冒充原版**（R1 / R9）。
因此每一行只有三种状态：

| 状态 | 含义 | 该怎么办 |
|---|---|---|
| **对齐** | 与原版依据完全一致 | 保持 |
| **推算占位** | 有依据、但数值/名称为本项目推算 | 是**待办**：等新证据或等裁定后替换 |
| **缺依据** | 归档里查不到 | 要么接受永久缺失（D6），要么继续找证据 —— **不许编** |

### 踩过的坑（重要，别重复踩）
1. **编码不能靠"谁的解码坏字符少"来判定**。GBK 几乎能解码任意字节序列且不产生替换字符，
   这个判据永远偏向 GBK。正确做法：读 HTML 自己声明的 `charset`。
2. 5068 正文页里有 SSI include 失败留下的坏字节（`���� SSI �ļ�ʱ����`），
   会让"UTF-8 坏字符比例 < 0.2%"的判据误判，导致整页被当 GBK → 全篇乱码。
3. **乱码检测不能用 U+FFFD**，因为页面自带的 SSI 残留就含 U+FFFD。
   要检测"UTF-8 被当 GBK 读"才会出现的特征字（鍒/澶/氬/厠/銆/锛…）。

## 二、官方数值模型

### 2.1 八项属性（来源：7k7k《多克多比属性介绍》179075）

原文逐条：

| 属性 | 官方说明原文 |
|---|---|
| 生命 | 多比的 HP，被怪物击中就会损失 |
| 魔法 | 多比的 MP，战斗中使用技能就会消耗 |
| 攻击 | **影响多比力量型技能攻击力**的数值 |
| 魔攻 | **影响多比精神力技能攻击力**的数值 |
| 命中 | 影响使用各种技能成功率的数值 |
| 回避 | 影响被攻击时闪避的数值 |
| 防御 | 影响被**物理**攻击伤害减免的数值 |
| 魔防 | 影响被**魔法**攻击伤害减免的数值 |
| 暴击 | 使用技能出现暴击的数值 |
| **速度** | **直接影响多比是否能够快速进入回合**的数值 |

原文结语：「据说多比们还有**好几种隐藏属性**。而且随着多比等级的不断提升，这些属性都会成长。」

**结论**：原版是**双伤害通道**（攻击→力量型技能 / 魔攻→精神力技能），且**有出手顺序系统**（速度）。
我们当前版本只有单通道、无速度排序 → 待补。

### 2.2 数值公式骨架（来源：5068《分析多克多比的计算公式打怪攻略》928）

原文给出的是公式**结构**（a/b/c/d 为原作者隐去的系数）：

```
升级经验 EXP = a((Lv^3) + (b*Lv)) + c
生命 = int(力量*a/10) + int(体质*b/10) + int(Lv*c/10) + d
魔力 = int(魔力*a/10) + int(技巧*b/10) + int(Lv*c/10) + d
攻击 = int(力量*a/10) + int(技巧*b/10) + c
防御 = int(体质*a/10) + int(敏捷*b/10) + c
魔攻 = int(魔攻*(((a*b/10) + c)/b)) + d
魔防 = int((体质*a + 魔力*b)/c) + d
命中 = 技巧*a/b + int(幸运/c) + d
回避 = 敏捷*a/b + int(幸运/c)
暴击 = int((幸运*a + 技巧*b)/c) + d
实际命中 = a + (攻方命中 - 守方回避)*b/(10*攻方等级)
魔法伤害 = int(((攻方魔攻*(100+技能系数))/100)+技能基值) * a * (900+b) * (100-守方魔防) * 相克系数 / 10000000
```

可用信息：
- 技能有 `技能系数` 与 `技能基值` 两个字段
- **魔防是"100 − 魔防"的百分比减伤**（不是减法）
- 有独立的 `相克系数`
- 暴击由 幸运 + 技巧 决定；命中/回避由 技巧/敏捷/幸运 决定

### 2.3 技能分类（来源：5068《多克多比技能大全》42619）

原文三大类：
- **辅助系** → 细分为 恢复系 / 治疗辅助 / buff辅助
- **攻击系** → 单体攻击 / 群体攻击 / buff单体攻击 / buff群体攻击
- **被动系** → 暴击、体力上限等，不需使用自动生效

原文还提到一个关键机制：「不要犯那种**派出毒多比一身光系技能**的低级错误」
→ 说明存在**同属性技能加成**。

## 三、结印技能（原版最具特色的机制，我们此前完全没有）

来源：7k7k《多克多比结印技能特点》179172。原文要点：

1. **威力强大**：「结印技能有单体也有群体，但是无论哪种结印技能威力都十分强大，**远远超出普通技能的威力**」
2. **无消耗**：「技能的释放都需要消耗多比的魔法能量，但是**结印技能却并不需要消耗魔法能量**」
3. **释放条件**：每次释放需要消耗 **SP**。玩家在战斗中**被怪物攻击或者攻击怪物都会得到 SP**，
   SP 槽到顶峰积累 1 SP。**每个多比最多积累 3 SP**。普通战斗往往刚积累 1 SP 就结束了
   ——「这也是许多玩家没有发现结印技能的最主要原因」，**只有 BOSS 战才用得上**。
4. 攒到 SP 后结印技能图标才会变亮。
5. **结印操作**：「多克多比**首创结印式**结印技能释放」，选择释放后出现结印操作，
   玩家在**规定时间内**用键盘**上下左右**按键结印，**成功结印越多威力越大**。

→ 这条完全对应我们数据里的 11 个 0MP 且 CD≥4 的技能（石枪阵、多重火球、大地之怒、暴风雪、
风羽箭、飓风、连动冲击、流沙地狱、群体恢复、重水爆、重水弹）。

## 12.1 副本通用规则（来源：`7k7k/115164`、`7k7k/179182`）

- **只有组队才能进入副本**；副本是"单独为你和你的队伍创造的一个游戏空间"，里面不会出现其他玩家
- 副本分**单人副本**和**多人副本**
- 都是从**特定 NPC 传送**进去的（例：迷失里的**拉鲁**把队伍传送到金字塔）
- 完成副本冒险可以收获**只有在副本里才能获得的「魅力」属性** ← 这条很关键，魅力是副本专属产出

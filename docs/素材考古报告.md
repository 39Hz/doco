**关键**：每帧 **1920×2112 或 1920×1408**，透明背景、角色居中对齐。
游戏内实际显示只有几十像素，所以这些帧**可以缩放出任意尺寸的干净精灵图**。

以龙多比为例，每个形态有完整的 10 组动作：

```
龙多比普通姿态   29 帧   龙多比战斗姿态   30 帧
龙多比发招一     29 帧   龙多比发招二     33 帧
龙多比发招三     30 帧   龙多比发招四     26 帧
龙多比发招五     25 帧   龙多比战斗胜利   25 帧
龙多比躲闪       29 帧   龙多比防御       21 帧
```

**关于重复帧**：序列内有 1599 个完全重复帧（512 MB）。经核查这**不是冗余备份**，
而是原版逐帧导出的**停格帧**（角色保持数帧不动来控制节奏），属于动画时序信息，不能删除。

## 四、素材瑕疵与风险

| 项 | 情况 | 影响 |
|---|---|---|
| `Message_01.mp3` | 文件头 261 字节全零填充，音频本体完好 | 可播，无影响 |
| 原声缺 `music006` | 20 首而非 21 首 | 少一首 BGM |
| 场景图来源 | 微博相册截图，非原始资源包 | 有轻微 JPEG 压损，且**角色被烘焙进背景** |
| 98% 的场景未命名 | 只有标题画面和世界地图已识别 | 需你确认或按画面自行命名 |
| `.fla` 无法直接解析 | 是 OLE 复合文档，需要专业工具 | **但已有导出 PNG，绕过了这个问题** |
| 压缩包内 24 个 `.rar` | 7z 未抽取其内容 | 里面可能还有素材 |

|---|---|---|
| 场景背景 | ✅ 完整 | 86 张原版分辨率场景图 |
| 角色精灵与动画 | ✅ **极好** | 9 形态 4189 帧全分辨率，10 组动作 |
| 怪物与战斗动画 | ✅ 好 | `.fla` 源工程 + 已导出序列 |
| 战斗数值 | ✅ **完整** | 十维属性 + 技能 CD/耗能/范围 |
| 刷怪分布 | ✅ 有 | 场景-怪物-等级对照 |
| 背景音乐 | ✅ 好 | 20 首原版循环段 |
| 界面音效 | ✅ 基本够 | 点击/悬停/提示 |
| UI 原件 | ⚠️ 部分 | 有 icon 源文件，但整套 UI 需从截图重绘 |
| **任务剧情** | ✅ **完整** | 主线 14 + 支线 22 篇原始文案 |
| **玩法规则** | ✅ 有文档 | 攻略文档记录了副本与小游戏机制 |

**结论**：除"联机"和"完整 UI 套件"外，其余要素素材齐备。
做到**单机可玩、数值忠实、剧情完整**是现实的，不需要任何猜测性推断。

## 4. 常用命令

```bash
node _tools/run-all-tests.mjs        # 全量回归（自动发现测试，禁止硬编码清单）
node _tools/fidelity-report.mjs      # 重新生成保真度报告
node _tools/scan-corpus.mjs          # 在语料里查证"只有名字"的系统
node _tools/scan-corpus.mjs dungeons # 在语料里查证 14 个副本
node _tools/shoot.mjs docs/shots --ui-only   # 重拍界面截图
node _tools/check-minigame-balance.mjs       # 小游戏"能不能正常玩"体检（机器人试玩，量通关率与耗时）
node _tools/check-dungeon-playthrough.mjs    # 副本"能不能从头打到尾"体检（机器人试玩 13 个副本）
node _build/make-dist.mjs            # 组装 dist + 编译 exe
node _tools/verify-zip.mjs           # 校验发布包内容完整
```

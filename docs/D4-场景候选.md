## 三、为什么我停在这里（没有直接加进游戏）

加进游戏**不是加一张图那么简单**，要动的是**世界结构**：

1. 得给它们分配 **scene id（89–93）**；
2. 得决定**归哪座岛** —— 而现有 11 座岛（王城 · 中央大陆 / 沙漠遗迹岛 / 云端神殿岛 / 集市港岛 /
   草原野外 / 熔岩火山岛 / 珊瑚秘境岛 / 地精工坊岛 / 浮空碎石台 / 森林岛 / 云海孤丘 · 霜原）
   **没有一座能对上**：
   - 云中城堡 / 城堡大厅 / 燃烧瀑布 在归档的**主场景目录**里，没有分组线索；
   - 幽水宫 / 邪力宫殿 在 `多克多比新场景图/天空裂缝/` 里 —— 归档用**目录名「天空裂缝」**把它们归成一组，
     但**世界地图里没有这座岛**（`天空裂缝` 只在这个归档目录名里出现过）。
3. 一旦岛选错，就是**把官方场景放到了错误的位置** —— 这属于 D3（场景结构/命名）那一类，
   而计划书明确写着 **D3 是"唯一人类必答项"**。

按 R9「不许拿'看起来像'的顶替」，我不猜岛。
